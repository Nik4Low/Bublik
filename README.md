# Torus Rotation

Проект демонстрирует вращение 3D тора (бублика) с использованием Java Swing.

## Описание

Приложение создает трехмерный тор и отображает его вращение вокруг всех трех осей (X, Y, Z) в реальном времени. Тор отображается в виде каркасной модели с линиями, соединяющими вершины.

## Требования

- Java 11 или выше
- Никаких дополнительных зависимостей не требуется

## Запуск

### Способ 1: Использование bat-файла (Windows)
```
run.bat
```

### Способ 2: Ручная компиляция и запуск
```bash
# Компиляция
javac -d target src/main/java/Main.java

# Запуск
java -cp target Main
```

## Управление

- Приложение запускается автоматически
- Тор вращается вокруг всех трех осей с разной скоростью
- Для закрытия приложения используйте кнопку X в окне

## Технические детали

- Использует Java Swing для отображения
- Реализовано 3D вращение с матрицами преобразований
- Анимация работает с частотой ~60 FPS
- Тор создается с параметрами: радиус большой окружности = 0.5, радиус малой окружности = 0.2
